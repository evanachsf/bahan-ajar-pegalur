    <h1 style="text-align: center; font-family: 'Lucida Sans', 'Lucida Sans Regular', 'Lucida Grande', 'Lucida Sans Unicode', Geneva, Verdana, sans-serif;"> 📖 Bangun Ruang Prisma 📖</h1>
    
    <img src ="https://tse3.mm.bing.net/th/id/OIP.DkedjacDF84ZZcRBu31NbwHaEK?pid=Api&P=0&h=220" sizes="width 200 px height 127 px" style="display: block; margin: 0 auto;"

    <p style="text-align: center;font-family: Verdana, Geneva, Tahoma, sans-serif;"><strong> Apa itu Prisma? </strong></p>
    <p>Pernah lihat kotak susu? Bentuknya punya sisi depan dan belakang yang sama besar, kan? Bagian atas dan bawahnya juga sejajar, sedangkan sisi-sisinya berupa persegi panjang.</p>
    <img src="https://png.pngtree.com/png-clipart/20221027/ourlarge/pngtree-susu-kotak-png-image_6389272.png" width="250" 
  style="display: block; margin: 0 auto;">
    <p>Secara umum, Prisma merupakan bangun ruang tiga dimensi yang tersusun atas dua bangun datar yang sejajar dan kongruen (memiliki bentuk serta ukuran yang sama) sebagai alas dan tutupnya. Sementara itu, sisi-sisi tegaknya berupa bidang persegi panjang yang berfungsi menghubungkan kedua alas tersebut. Penamaan suatu prisma didasarkan pada bentuk alasnya. Apabila alasnya berbentuk segitiga, bangun tersebut disebut prisma segitiga, dan jika alasnya berbentuk segilima, maka dinamakan prisma segilima. </p>
    <p><strong> Jenis-Jenis Prisma </strong></p>
    <p>Macam-macam prisma dibedakan berdasarkan bentuk alas dan tutupnya, di antaranya sebagai berikut:</p>
    <p><strong> 1. Prisma Segitiga </strong></p> 
    <img src="https://4.bp.blogspot.com/-MXF41jxmQHs/VXfTGzcI1zI/AAAAAAAACRc/xwVpluAi870/s1600/Teknik%2BMenghitung%2BRumus%2BPrisma%2BSegitiga%2BLuas%2Bdan%2BVolume%2BLengkap.png" width="150" style="display: block; margin: 0 auto;">  
    <p> Dari gambar diatas dapat kita ketahui bahwa prisma segitiga memiliki alas dan tutup yang berbentuk segitiga, sehingga memiliki lima sisi, yakni tiga sisi tegak, satu alas, dan satu tutup.</p>
    <p><strong> 2. Prisma Segiempat </strong></p> 
    <img src="https://tse4.mm.bing.net/th/id/OIP.O5LpliyrHQopGGeW473v4wAAAA?pid=Api&P=0&h=220" style="display: block; margin: 0 auto;"> 
    <p>Dari gambar diatas dapat kita ketahui Prisma segiempat memiliki alas dan tutup yang berbentuk segiempat, sehingga memiliki enam sisi, yakni empat sisi tegak, satu alas, dan satu tutup. Pada prisma segiempat, terdapat bentuk khusus, yaitu balok dan kubus.</p>
    <p><strong> 3. Prisma Segilima </strong></p> 
    <img src="https://tse1.mm.bing.net/th/id/OIP.NyEGGGgS-RzY148uZUI3CQAAAA?pid=Api&P=0&h=220" style="display: block; margin: 0 auto;">
    <p>Dari gambar diatas Prisma segilima memiliki alas dan tutup yang berbentuk segilima, sehingga memiliki tujuh sisi, yakni lima sisi tegak, satu alas, dan satu tutup.</p>
    <p><strong> 4. Prisma Segienam </strong></p> 
    <img src="https://tse1.mm.bing.net/th/id/OIP.mLEpMa1aZtuRe9t-UInnkwAAAA?pid=Api&P=0&h=220" style="display: block; margin: 0 auto;">
    <p>Dari gambar diatas Prisma segienam memiliki alas dan tutup yang berbentuk segienam, sehingga memiliki delapan sisi, yakni enam sisi tegak, satu alas, dan satu tutup</p>
    <p><strong> 5. Prisma Segi-n </strong></p> 
    <img src="https://tse4.mm.bing.net/th/id/OIP.UaAyouiNjRKuM95ElL16XAAAAA?pid=Api&P=0&h=220" style="display: block; margin: 0 auto;">
    <p>Dari gambar diatas Selain yang sudah disebutkan di atas, ada juga jenis prisma segi-n. Contohnya prisma segi-7, prisma segi-8, prisma segi-9, prisma segi-10, dan seterusnya</p>
    <p><strong> 6. Tabung </strong></p> 
    <img src="https://tse2.mm.bing.net/th/id/OIP.WcCY-BIMMg8OBuFDbBeD3gHaC7?pid=Api&P=0&h=220" style="display: block; margin: 0 auto;"> 
    <p>Dari gambar diatas Tabung merupakan jenis prisma khusus dimana alas dan tutupnya berbentuk lingkaran. Sehingga, memiliki sisi tegak atau selimut berupa sisi lengkung yang jika dibuka berbentuk persegi panjang.  Total sisinya menjadi 3, yakni alas, tutup, dan sisi lengkung.</p>
    <p><strong> Sifat-Sifat Prisma: </strong></p>
    <ul>
  <li>Memiliki dua bidang sejajar yang sama besar (alas dan tutup).</li>
  <li>Sisi tegaknya berbentuk persegi panjang.</li>
  <li>Jumlah sisi, rusuk, dan titik sudut bergantung pada bentuk alasnya.</li>
  <li>Penampang sejajar dengan alas selalu sebangun.</li>
  <li>Volume = luas alas × tinggi prisma.</li>
  <li>Terdapat rumus khusus untuk mencari banyaknya rusuk, titik sudut, diagonal bidang, diagonal ruang, dan bidang diagonalnya, yakni:
    <ul>
  <p></p><li>Banyak sisi: n + 2</li>
  <li> Jumlah rusuk: 3n </li>
  <li>Jumlah titik sudut: 2n</li>
  <li>Banyak diagonal sisi/bidang: n(n-1)</li>
  <li>Banyak diagonal ruang: n(n-3)</li>
  <li>Banyak bidang diagonal, jika n genap: ½n(n-1)</li>
  <li>Banyak bidang diagonal, jika n ganjil: ½n(n-3)</li>
  </ul>

    const answers = {
      q1: 'b',
      q2: 'a',
      q3: 'b',
      q4: 'c'
    };

    document.getElementById('quizForm').addEventListener('submit', function(e){
      e.preventDefault();
      const form = e.target;
      const data = new FormData(form);
      const name = data.get('nama')?.trim();
      const kelas = data.get('kelas')?.trim();

      let score = 0;
      let total = 5;
      const details = [];

      ['q1','q2','q3','q4'].forEach(q => {
        const val = data.get(q);
        const correct = answers[q];
        if(val === correct){ score += 1; details.push({q,ok:true}); }
        else { details.push({q,ok:false, given:val, correct}); }
      });

      const q5 = data.get('q5');
      const expectedQ5 = 120;
      const q5num = parseFloat(q5);
      if(!isNaN(q5num) && Math.abs(q5num - expectedQ5) < 1e-6){ score += 1; details.push({q:'q5',ok:true}); }
      else { details.push({q:'q5',ok:false, given:q5num, correct:expectedQ5}); }

      const percent = Math.round((score/total)*100);
      const fb = document.getElementById('feedback');
      fb.innerHTML = '';

      const resultBox = document.createElement('div');
      resultBox.className = score === total ? 'result' : 'wrong';
      resultBox.innerHTML = `<strong>Hasil: ${score} / ${total} (${percent}%)</strong>`;
      fb.appendChild(resultBox);

      details.forEach(d => {
        if(!d.ok){
          const el = document.createElement('div');
          el.className = 'explain';
          if(d.q === 'q5'){
            el.innerHTML = `<strong>Soal 5:</strong> Jawaban Anda: ${d.given ?? 'kosong'}. Jawaban benar: ${d.correct}. (Luas alas = 0.5 × 6 × 4 = 12 cm³; Volume = 12 × 10 = 120 cm³)`;
          } else {
            const txtGiven = d.given ?? 'tidak menjawab';
            el.innerHTML = `<strong>Soal ${d.q.slice(1)}:</strong> Jawaban Anda: ${txtGiven}. Jawaban benar: ${d.correct}.`;
          }
          fb.appendChild(el);
        }
      });

      try{
        const attempts = JSON.parse(localStorage.getItem('kuis_prisma_attempts') || '[]');
        attempts.push({nama:name||null,kelas:kelas||null,score, total, time:new Date().toISOString()});
        localStorage.setItem('kuis_prisma_attempts', JSON.stringify(attempts));
      }catch(e){/* ignore */}

      resultBox.scrollIntoView({behavior:'smooth', block:'center'});
    });

    document.getElementById('resetBtn').addEventListener('click', function(){
      document.getElementById('quizForm').reset();
      document.getElementById('feedback').innerHTML = '';
    });
  </script>
